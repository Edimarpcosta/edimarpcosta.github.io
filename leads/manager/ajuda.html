Ajuda — Gestor de Leads PRO (linha v7.4.x)

Manual do básico ao avançado: importação MapsScraper, clientes ativos, ícones, backup, Google Sheets (modo completo com Web App), sincronização bidirecional, vínculo Lead↔Cliente e cuidado crítico com Latitude/Longitude no Sheets (pt-BR).

Atualizado em: 2026-02-15 06:12 Compatível com: v7.4.4+ Conector recomendado: Apps Script v1.4.2+ / v1.4.1+
Regra de ouro: o Gestor salva dados localmente no navegador (IndexedDB/localStorage).
  • NÃO apague cookies/dados do site (isso pode apagar seu banco local).
  • Use Backup e/ou sincronize com Google Sheets (modo completo).
Crítico (GPS): em planilhas pt-BR, o Google Sheets pode interpretar ponto como separador de milhar e “quebrar” coordenadas.

A solução ideal (já implementada nas versões novas) é gravar Latitude/Longitude como TEXTO no Sheets e manter como string no app.

1) Começar rápido

  1. Abra o Gestor (Chrome recomendado).
  2. Escolha o Conjunto no topo (ex.: “Leads Padrão”).
  3. Importe seus Leads (XLSX/CSV do MapsScraper).
  4. Importe Clientes Ativos (Clientes.xlsx no padrão de colunas).
  5. Faça um Backup e/ou configure Google Sheets (Web App) para sincronizar em outros dispositivos.
Dica: usar como “app” no celular

No Android (Chrome): menu ⋮ → Adicionar à tela inicial. Assim ele abre como um app.

2) Conceitos: Lead x Cliente

Lead
  • Prospect capturado (ex.: Google Maps).
  • Você registra funil, próxima ação, interesse e observações.
  • Pode ter CPF/CNPJ para enriquecer dados e facilitar cadastro.
Cliente Ativo
  • Já compra da empresa.
  • Campo-chave: Cód. Cliente (código interno).
  • Tem dias de entrega, dia de visita, comprador, produtos de interesse.

3) MapsScraper: padrão de colunas (XLSX)

O Gestor suporta o XLSX padrão do MapsScraper (como seu “Rio_Claro Exemplo.xlsx”). Ele costuma vir com campos como:

  • Name, Category, Fulladdress, City, State, Zip
  • Phone, Website, (às vezes Email)
  • Latitude, Longitude (alta precisão)
  • Google Maps URL (às vezes com cid=...)
  • Facebook, Instagram, Twitter
  • Social Medias (pode vir como JSON)
  • Rating, Reviews
Redes sociais: o Gestor lê Facebook/Instagram/Twitter tanto das colunas individuais quanto do campo Social Medias (JSON).

4) Leads: fluxo e campos

  1. Abra Maps 🗺️Maps para conferir o ponto.
  2. Contato WhatsApp 📱WhatsApp (sem mensagem) ou com template opcional.
  3. Registre observações e defina Próxima ação.
  4. Se virar cliente, converta/exporte para o padrão de clientes ativos.
Campos importantes no Lead
  • cid e url (Maps URL/CID) ajudam a identificar e evitar duplicados.
  • lat e lng para navegação GPS real (mantidos com precisão total).
  • doc e docDigits para CPF/CNPJ (enriquecimento).
  • cod (opcional): ajuda a vincular lead com cliente ativo (código interno).

5) Clientes: fluxo, Cód. Cliente e campos extras

Novidade v7.4.x: clientes podem armazenar também (opcional) os campos de “contato/links/GPS”:

phone, email, website, instagram, facebook, twitter, cid, url, lat, lng, doc, docDigits, sourceLeadId

Esses campos não são obrigatórios, mas ficam disponíveis no modal de Cliente Ativo para preencher e sincronizar.

6) Ligação Lead ↔ Cliente (chaves)

O Gestor consegue identificar que “um lead já é cliente” e sincronizar dados por uma ou mais chaves:

  • convertedClientId (link direto do lead para o cliente gerado)
  • cid (Google Maps CID)
  • cod (Lead) ↔ codCliente (Cliente)
  • telefone (comparando lead.phone com client.whatsapp e client.phone)
Como a sincronização funciona:
  • Por padrão, o sistema preenche campos vazios (não sobrescreve o que já está preenchido).
  • Assim, dados ricos (lat/lng, url/cid, redes sociais) podem ser “enriquecidos” do lead para o cliente.

7) Agenda / Próximas ações

A Agenda junta os itens com “Próxima ação” e “Próxima visita”, incluindo atrasados.

8) Conjuntos

Um Conjunto é um “banco separado” dentro do Gestor (campanhas/rotas/cidades).

No modo Google Sheets (Web App), cada conjunto grava em:

  • LEADS__<setId>
  • CLIENTS__<setId>

9) Backup e Importar Backup

  • 💾Backup baixa um JSON com todos os dados do navegador.
  • 📥Importar Backup restaura esse JSON.

10) Google Sheets: modo simples x modo completo

Modo simples (API Key) — Somente leitura
  • Importa dados do Sheets para o Gestor.
  • Não escreve de volta.
Modo completo (Web App / Apps Script) — Bidir
  • Pull (puxar) + Push (enviar)
  • Auto-cria abas (SETS/SETTINGS/LEADS__/CLIENTS__)
  • Ideal para sincronizar em outro celular/PC

11) Passo a passo: Web App (Apps Script)

11.1) Abrir Apps Script dentro da planilha

  1. Abra a planilha no Google Sheets.
  2. Vá em Extensões → Apps Script.

11.2) Colar o código .gs

  1. Abra o arquivo Código.gs (ou Code.gs).
  2. Apague o conteúdo atual.
  3. Cole o conteúdo do conector (ex.: Ameripan_SheetsConnector_AppsScript_v1.4.2.gs).
  4. Clique em Salvar (ou Ctrl+S).

11.3) Implantar como Web App

  1. Clique em Implantar (canto superior direito).
  2. Nova implantação → tipo Aplicativo da Web.
  3. Configure:
    • Executar como: Você
    • Quem pode acessar: Qualquer pessoa com o link
  4. Clique em Implantar.

11.4) Autorizar

  1. Quando pedir permissões, clique em Autorizar.
  2. Escolha sua conta.
  3. Se aparecer “Aplicativo não verificado”: Avançado → Ir para (seu projeto).

11.5) Copiar a URL /exec

Exemplo: 
https://script.google.com/macros/s/AKfycby1UN595v1EPq6BZgJ_rUIv1F63S0PKrR5am7HewoE8CkM1zr4uxjvmXAG2fKxmXLYS-g/exec

Copie a URL que termina em /exec (é a URL do Web App).

11.6) Onde colar a URL no Gestor

  1. Abra o Gestor → 🧩Config
  2. Seção “Google Sheets — Modo completo (Web App)”
  3. Cole no campo Web App URL
  4. Salvar/Testar

12) Push/Pull (bidir) e organização das abas

O Web App organiza a planilha em abas:

  • SETS → lista de conjuntos
  • SETTINGS → configurações
  • LEADS__default, CLIENTS__default → dados do conjunto “default”
  • Se você criar outros conjuntos: LEADS__<setId> e CLIENTS__<setId>
Recomendação:
  1. No dispositivo novo: faça Pull
  2. No final do dia: faça Push

13) Latitude/Longitude sem conversão (garantia total)

Problema comum (pt-BR): o Sheets pode tratar “.” como separador de milhar e destruir coordenadas.

Ex.: -47.555873899999995 vira -47.555.873.899.999.900

Como garantir que nunca estrague:

  1. No Sheets, formate colunas Latitude e Longitude como Texto simples (Formatar → Número → Texto simples).
  2. Use o conector atualizado (Apps Script v1.4.1+), que força formato texto automaticamente.
  3. No Gestor, coordenadas ficam salvas como string e só viram número na hora do GPS.
Se já estragou, como corrigir?
  • Formate as colunas como Texto simples.
  • Faça um Pull e depois Push (as versões novas corrigem e regravem).

15) FAQ e problemas comuns

Não consigo acessar o Web App / dá 403
  • Confirme que “Quem pode acessar” está como Qualquer pessoa com o link.
  • Confirme que você está usando a URL que termina em /exec.
  • Se você editou o código, atualize a implantação (nova versão).
Meus dados sumiram
  • Se você limpou dados do site, pode ter apagado o banco local.
  • Use Importar Backup ou faça Pull (se você sincroniza no Sheets).
WhatsApp não aparece
  • O ícone aparece somente se o telefone for válido.
  • Preferir salvar com DDI: +55...
